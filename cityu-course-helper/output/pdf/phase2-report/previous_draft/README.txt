  TeX Live 2025 is installed on D: on this machine. Build caches and temporary

  Keep ge2340_project.sty and figures/ beside the .tex file.
  Other phase templates are not dependencies of this standalone report.

hash, base-model revision and experiment-file hashes. No training or model
inference was run while producing this report. All figures and quantitative
claims refer to the preserved experiment snapshots described in the report.
