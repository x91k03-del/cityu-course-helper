Part II Course Details
Abstract
2         CS2403: Data Management and Cloud Storage
This course is aimed at equipping students with the knowledge of database design, as well as, the ability to use database
management systems in an eﬀective manner.  The course will also provide the knowledge of how to use a relational
database system (RDBMS) for analytical processing.  For the cloud storage part of the course, the students will also learn
how to use an elastic computing service to host a database and retrieve data from it.
